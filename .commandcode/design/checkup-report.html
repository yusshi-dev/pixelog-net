P0 · HIGH · COLOR

Undefined CSS variables invert the type hierarchy

src/styles/global.css:1-11 defines --ink, --ink-mid, --ink-sub, --ink-mute — but not --ink-faint or --ink-light. tags.astro and categories.astro reference --ink-faint 11 times; posts.astro references --ink-light twice. Undefined properties make color fall back to inherited near-black, so "faint" meta text renders darker than "mute" text.

Define --ink-faint in :root (e.g. #8a8178) or replace all uses with --ink-mute.
Reach: 2 pages, 4 distinct text roles
P0 · HIGH · CONTRAST + ZOOM

--ink-mute misses AA and the input triggers iOS zoom

globals.css:9 #7a726a on #f7f5f2 is ~4.35:1 and carries every date, count, and section label at ~9.6px. posts.astro:81 sets the input to 0.85rem (~13.9px), below the 16px threshold that makes iOS Safari zoom on focus.

Darken --ink-mute to ~#6b635b (≈5.0:1) and set the input font-size to 1rem on screens under 640px.
Reach: global meta text + every mobile search
